# Library Management System

Application web de gestion de bibliothèque développée avec Django 5.

## 🎯 Objectif

Gérer les auteurs, livres, adhérents et emprunts d'une bibliothèque.

## 🧱 Stack technique

- **Langage** : Python 3.12
- **Framework** : Django 5.x
- **Base de données** : MySQL 8
- **Conteneurisation** : Docker + Docker Compose
- **Tests** : pytest, pytest-django
- **Qualité** : Ruff, Black, Mypy, pre-commit
